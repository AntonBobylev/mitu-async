# mitu-async

Клиент-серверное приложение на Node.js, которое реализует передачу данных через WebSocket-соединение между сервером и веб-клиентом в реальном времени.

## Особенности реализации
- **Backend**: Разработан на Node.js с использованием библиотеки `ws` и встроенного модуля `http` для раздачи статического контента и управления WebSocket-соединениями (`WebSocket.Server`).
- **Frontend**: Простой и адаптивный веб-интерфейс на HTML5/CSS3 с динамическим обновлением DOM-элементов при получении новых данных по WebSocket (`onopen`, `onmessage`, `onclose`).
- **Автономный поток данных**: Сервер включает встроенный асинхронный генератор тиков (`setInterval`), транслирующий актуальные котировки `BTCUSDT` клиентам, что обеспечивает стабильную работу приложения независимо от внешних сетевых и географических ограничений.

## Требования
- Предустановленный **Node.js** и **npm**

## Установка и запуск
1. Клонируйте репозиторий или распакуйте архив проекта.
2. Перейдите в файл проекта.
3. npm install
4. node server.js
5. Откройте в браузере веб-страницу приложения: http://localhost:8080

## Структура проекта
* server.js — точка входа бэкенда, WebSocket-сервер и обработчик клиентских подключений.
* public/index.html — клиентская часть (HTML-интерфейс, стили и логика WebSocket-клиента).
* package.json — конфигурационный файл Node.js с зависимостями.
